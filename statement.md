# Project Statement

## Problem Statement

Students often have to wait in queues at college canteens to place food orders. Manual order handling can also make it difficult to manage menu items and order status.

## Scope

CampusBite provides a simple Java application for viewing food items, managing a cart, placing orders and managing orders from an admin section.

## Target Users

- College students
- Canteen administrators

## High-Level Features

- Food menu
- Food search
- Cart management
- Order placement
- Order history
- Admin menu management
- Order status updates
