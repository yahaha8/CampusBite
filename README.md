# CampusBite

CampusBite is a Java-based canteen food ordering and management system.
# project overview
-CampusBite is a Java-based console application developed for managing food ordering in a college canteen.

-The system allows students to view the canteen menu, search for food items, add items to a cart, remove items, place orders, and view their order history. An admin section   is also provided for managing food items and updating order status.

-The project is developed using core Java concepts such as classes and objects, inheritance, polymorphism, ArrayList, enum, packages, and exception handling.

-The current version stores data during the application session and does not use a database.


## Features

- View food menu
- Search food items
- Add and remove items from cart
- Place orders
- View order history
- Admin menu management
- Food availability management
- Order status management
- Bill calculation

## Technologies used

- Java
- Object-Oriented Programming
- ArrayList
- Exception Handling
- File I/O can be added for persistent storage

##  steps on how to Run all this 
Step 1: Clone the Repository
Step 2: Check the Project Files
The Java source files are located inside:
                            src/campusbite/
step 3:Open the terminal in the root CampusBite folder.
Compile the Java source files using:
                            javac -d out src/campusbite/*.java
step 4:If compilation is successful, run the application using:
                            java -cp out campusbite.Main
