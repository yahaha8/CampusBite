# CampusBite

CampusBite is a Java-based canteen food ordering and management system.

## Features

- View food menu
- Search food items
- Add and remove items from cart
- Place orders
- View order history
- Admin menu management
- Food availability management
- Order status management
- Bill calculation

## Technologies

- Java
- Object-Oriented Programming
- ArrayList
- Exception Handling
- File I/O can be added for persistent storage

## How to Run

Open the project in IntelliJ IDEA, Eclipse or another Java IDE.

Run:

src/campusbite/Main.java

## Users

The application currently provides Student and Admin sections through the main menu.
